# Story 21.9: Account Picker Screen

Status: done

## Story

As a user with multiple accounts on my device,
I want to see all my accounts in a picker and tap to switch,
so that switching accounts is fast and doesn't require re-typing credentials.

## Acceptance Criteria (ACs)

1. **Given** 3 accounts exist on device (2 cloud, 1 local)
   **When** the account picker is displayed
   **Then** all 3 accounts show with correct name, email, tier badge (cloud/local icon), last-used date, and session status

2. **Given** a cloud-born account with a valid cached Firebase session
   **When** the user taps the tile
   **Then** account switches in < 200ms — dashboard appears with that account's data

3. **Given** a cloud-born account with an expired/missing Firebase session
   **When** the user taps the tile
   **Then** sign-in page opens with email pre-filled

4. **Given** a local-born account in the picker
   **When** the user taps the tile
   **Then** password prompt appears; correct password → switch; wrong → inline error

5. **Given** the user swipes left on a cloud-born tile
   **Then** "Remove from device" action is revealed

6. **Given** the user swipes left on a local-born tile
   **Then** "Delete account" action is revealed

7. **Given** the picker is displayed
   **Then** accounts are ordered by lastUsedAt descending (most recent first)

### Architecture patterns
- Use `ConsumerWidget` (not StatefulWidget) — state lives in providers
- `Dismissible` with `confirmDismiss` for the swipe-to-remove/delete
- `showDialog` for the local-born password prompt — `TextFormField(obscureText: true)` + "Sign In" button
- Cloud session detection: `FirebaseAuth.instance.currentUser` is synchronous (cached), no await needed

### Testing
- Widget tests with `ProviderScope` overrides for `deviceAccountsProvider`
- Mock `FirebaseAuth` for `tryResumeCloudSession` (use `firebase_auth_mocks` or mocktail)
- Test swipe-to-dismiss reveals correct action per tier

### Guardrails
- NEVER show passwords in plaintext in the picker
- NEVER auto-delete on swipe — always confirm first via `confirmDismiss`
- Tile tap must be disabled while a switch is in progress (_isLoading guard)
- The picker must NOT open any user DB — it reads only from the device registry
