## Decisions carried from the UX run

- Keep the existing Learning Tracker visual identity; dark phone mocks use canvas `#0B0F1A`, card `#151A26`, outline `#263041`, primary `#7CA0FF`, and ink `#EAEEF5`.
- Phone is the primary layout; tablet layouts were intended for each surface and are light-only, while dark mode is phone-only. Erev #09 has no tablet or dark mock.
- Mocks use English LTR; Hebrew terms follow the app's Hebrew Terms setting.
- Put sub-track capture rows below today's main-track tasks and a position summary on the Dashboard; manage sub-tracks in Settings → Manage tracks alongside the main track.
- Tri-state uses green for complete, amber with a dash checkbox for partial, and muted grey for empty.
- Parent/tutor off-track status is labelled “Behind pace”; the child never sees behind/off-track language.
- Child sub-track detail includes the capacity bar; children never see shortfall information.
- Shabbos/Yom Tov lock is the existing full-screen, unreadable overlay; #09 is the erev planned view with live controls. No dark or tablet erev mock was made.
- Catch-up reminder fires once when the card becomes available.
- Use the chosen FR-21 wording: “School may not reach Berachos perek 3 before July. About 40 mishnayos will return to home learning.”

## Ignore in mockups (drift)

- “Mishnayos Tracker” page titles should use the app name “Learning Tracker.”
- #02 adds a “Cheder” / “School track” badge to the Up to… sheet; the source is implied by the row being ticked.
- The ongoing tablet form adds a pace-health badge, projected annual volume, and parent tips; these are not product requirements.
- #10's “Record 13 mishnayos” count is illustrative; it lists only a subset, so the SPEC and PRD define the count and behaviour.
- #08 says assigned items sync across class benchmarks; PRD FR-13 keeps tracks independent and allows overlap without reconciliation.
- #09 planned rows have no checkboxes although the spine specifies live erev controls; use the live-control decision and PRD FR-24 for the planned view. The older `09-shabbos-locked-*` variants are superseded; FR-23's lock itself is the unreadable full-screen overlay, not a usable screen.

- FR-4a's onboarding mention is not mocked (the Manage tracks hub is #04); FR-10's greyed main-track ground and FR-12's return interaction are not shown; FR-8's delete-confirmation flow is not shown.
- FR-32's full per-source velocity report is not shown as a separate view (#14 only has per-source pace summaries).
- CAP-2 (correct a mistake), CAP-8's actual locked state, and CAP-13 (one learning store across the app) have no reference screen. FR-22 is withdrawn.
