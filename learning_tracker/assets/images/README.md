# App Images and Icons

This directory contains app icons, splash screens, and other visual assets.

## App Icon (Placeholder)

Currently using the default Flutter app icon. A custom icon should be designed and added here.

### Icon Requirements

- **Android**: Place icons in `android/app/src/main/res/mipmap-*/` directories
  - mdpi: 48x48
  - hdpi: 72x72
  - xhdpi: 96x96
  - xxhdpi: 144x144
  - xxxhdpi: 192x192

### Design Guidelines

For a Torah learning app, the icon should:
- Be simple and recognizable
- Use the app's color scheme (deep blue-purple primary color)
- Possibly incorporate Torah/learning symbolism (e.g., book, scroll, Hebrew letters)
- Be clear at small sizes
